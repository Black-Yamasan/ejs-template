# ejs-template

テンプレートエンジン「EJS」を使用したテンプレート

## Requirements

- Node.js: `24.13.0`
- pnpm: `12.5.1`

## commands

### install

```bash
pnpm i
```

### build for development

```bash
pnpm build:dev
```

### build for production

```bash
pnpm build:prod
```

### run server for development

```bash
pnpm start
```

### run test for javascript

```bash
pnpm test
```

### format

#### check

```bash
pnpm prettier:check
```

#### write

```bash
pnpm prettier:writer
```

### eslint

```bash
pnpm lint
```
